- RISC-V에서의 예외 처리
-- Event 발생
-- mdeleg 레지스터 확인 후, 어떤 모드에서 예외 처리를 할 지 결정.
-- 예외가 발생한 시점의 레지스터 값과 CSR들 저장.(아래는 csr)
    scause	예외 유형. 커널은 이를 읽어 어떤 종류의 예외인지 판단합니다.
    stval	예외에 대한 부가 정보(예: 문제를 일으킨 메모리 주소). 예외 종류에 따라 다르게 사용됩니다.
    sepc	예외가 발생했을 때의 프로그램 카운터(PC) 값.
    sstatus	예외가 발생했을 때의 운영 모드(U-Mode/S-Mode 등).
-- stvec 레지스터에 저장된 값이 프로그램 카운터로 설정 > 핸들러로 점프
-- 핸들러는 일반 레지스터를 별도 저장 후, 예외 처리.
-- 예외 처리 후, 실행 상태 복원 및 sret 동작
